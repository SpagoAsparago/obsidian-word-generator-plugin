How to Use
Patterns

Patterns contain the characters to generate the words. Different characters are separated by / have an equal chance of being selected in the word generation. New patterns can be created with the plus icon button.


Main Pattern

Words will be generated according to the sequence in the main pattern. To use patterns, their name must be enclosed between curly brackets like {C}, otherwise they will be treated as regular characters.


Optional Sequence

Characters or patterns enclosed between round brackets only have a 50% chance of being contained in the each word. Only the main pattern can contain optional sequences, any use of parenthesis in patterns will be ignored.


Settings

Settings can be viewed from the Community plguins tab in Obsidian settings or by clicking the button at the top of the page. It's possible to set the total amount of word generated as well as the possibility of displaying each word in a new line and filtering duplicated words.


Exporting and Importing Patterns

The save button will create a JSON file that store your patterns and main pattern, as well as the plugin settings, which can be later imported in order to use different pattern combinations. Note that while you can't see the JSON file unless you enable 'Show all file types' in Obsidian's options>files and links, but they can still be loaded using the upload button.
