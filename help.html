How to Use
Patterns

Patterns contain your word components. Use / to separate characters or groups with an equal chance of selection. Create new patterns with the + button.


Main Pattern

Words are built using this sequence. To reference a pattern, enclose its name in curly brackets, e.g., {C}. At least one pattern must be referenced.


Optional Sequence

Enclose characters or patterns in parentheses to give them a 50% chance of being used. Note: Optional sequences only work in the Main Pattern; parentheses inside individual patterns are ignored.


Settings

Access settings via the button at the top, the command or the Community Plugins tab. You can set the total word count, toggle "one word per line," and filter out duplicate results.


Saving patterns

Patterns save automatically when you click Generate or close the view. Use the save button to export your setup as JSON file. Use the upload button to import them. Note: you can enable "Show all file types" in Files & Links to view these files in your vault.
